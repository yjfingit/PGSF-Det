# PGSF-Det v4：对象级跨模态匹配 + 分类/定位非对称融合（TD-Fusion）

`architecture_version=4`，代码位于 `pgsf-det-v4`（V1/V2/V3 在该工程内完整保留，见文末兼容性测试）。

核心思想一句话：**先在目标级动态寻找跨模态对应区域，再按分类与定位的不同需求做非对称融合——
分类直接吃跨模态语义，定位始终以本模态空间特征为基础。**

## 一、数据流

```
RGB 图像 ─┐                                   ┌─ TIR 图像
          ├─ 独立 YOLO11s Backbone + Neck ────┤
          │      P2,P3,P4,P5（各自 1×1 统一到 128 通道）
          ├─ 独立多尺度 Proposal Head（逐尺度：C 类质量分 + 2 中心偏移 + 2 宽高 + 1 proposal quality）
          ├─ 跨尺度选 K=128 个候选（每尺度最低配额 + 其余全局按分数排序）
          ├─ 多尺度 RoIAlign → S ∈ R[B,K,128,r,r]（r=3）
          │      GAP → z ∈ R[B,K,128]
          │
          ├─ CFPM 双向粗到细候选匹配（唯一一次对象级跨模态交互）
          │      ① 语义检索：A = (W_Q z) (W_K z_other)^T / sqrt(64)   → 每候选 Top-L=2
          │      ② 局部探测：OffsetMLP(256→128→8) → 4 个二维偏移
          │         p = center_il + tanh(Δp_il) ⊙ size_il           （以对侧框宽高为尺度）
          │         每点预测 P2-P5 的 4 维 softmax 尺度权重，加权采样
          │         2 anchor × 4 点 = 8 个局部特征 → 注意力聚合 → z_other→self
          │
          ├─ 一致性与可靠性
          │      c = MLP([z, z', z⊙z', |z−z'|])          512→256→128
          │      r = sigmoid(MLP([z, z', |z−z'|, q_self, q_other, Top1−Top2 间距]))
          │
          └─ TD-Fusion（非对称）
                 分类： f_cls = z + r · W_c(c)             → 分类头 128→128→C
                 定位： γ = tanh(W_r c)，F_reg = S ⊙ (1 + α·r·γ)   （α 可学习，初始 0.1）
                       回归头用 F_reg + 本模态 coarse box 预测 4 维 delta
```

**V4 只有一个对象级交互**：不训练固定仿射、不写回中间特征图、没有第二个 Late Transformer。
`_affine_A` 仍注册用于旧 checkpoint 兼容，但已 `requires_grad_(False)` 且前向永不读取
（`tests/test_v4.py::test_affine_prior_has_no_effect_on_v4` 断言改动它输出逐比特不变）。

## 二、关键设计说明（为什么这样写）

### 1) 没有任何跨模态坐标运算
语义检索只用特征点积；局部探测的偏移**以对侧候选框的宽高为尺度**，没有任何相机参数（焦距、基线、预拟合 warp）。
`test_cfpm_offsets_scale_with_the_anchor_box` 把对侧框放大 2 倍，断言采样点相对锚点的位移恰好变成 2 倍；
`test_retrieval_is_appearance_only` 把对侧坐标整体平移 0.37，断言 `anchor_idx` 完全不变。

### 2) 定位只能被"通道调制"，不能吃到对侧空间特征
`F_reg = S ⊙ (1 + α·r·γ)`，其中 `S` 是本模态 RoI、`γ∈R^C` 是逐通道标量。
测试同时验证两件事：①`F_reg` 与公式逐元素相等；②对每个 (batch, candidate, channel) 存在唯一标量 gain 使
`F_reg == S · gain`（即空间上没有任何来自对侧的图案）；③端到端地重算回归头，输出与 `pred[..., :4]` 逐比特一致
（证明框头只吃了这一个输入）。最终框永远在本模态坐标系、以本模态 coarse box 为参考解码。

### 3) 分类确实吃到了跨模态语义
`f_cls = z + r·W_c(c)`。`test_classification_does_change_with_the_other_modality` 把 `W_c` 置为非零后断言
分类 logits 与纯单模态分支不同。

### 4) 初始化即"两个独立检测器"
`W_c`、`W_r` 零初始化（`α` 初始 0.1）。因此 `f_cls = z`、`γ = 0`、`F_reg = S`，整个融合在 step 0 是精确恒等：
两阶段迁移安全（`test_gate_and_modulation_are_identity_at_initialisation`、
`test_v4_stage_transfer_preserves_initial_detection` 断言 atol=1e-6），
且"匹配失败时本模态仍具备完整检测能力"这件事是结构性成立的。
反过来说，`L_self`（见下）保证了这条退路也有监督。

### 5) 辅助单模态损失不增加推理分支
`L_self` 用的是**同一套检测头**，只是输入换成未融合的 `z_m` / `S_m`。推理时不存在额外分支。

### 6) 两个被发现并修掉的真实陷阱
* **RoIAlign 半像素约定**：`torchvision.ops.roi_align(aligned=True)` 工作在"像素 i 覆盖 [i, i+1)"的连续坐标里。
  用 `grid_sample(align_corners=True)` 复刻会引入半像素系统偏移（实测最大偏差 0.375，正好是半个像素）。
  回退实现已改为 `align_corners=False` + `gx = 2x/W − 1`，并用线性斜坡给出了闭式解做双重校验。
* **双重零初始化门控导致梯度消失级联**：matcher 内部的注意力输出投影若也零初始化，就会和 TD-Fusion 的
  `W_c` 叠加成两个乘法零，使局部探测分支的梯度降到 ~1e-33（SGD 下近乎冻结）。现在 matcher 的聚合用常规小增益初始化
  （它是特征提取器，不是门），只有 TD-Fusion 的投影保持零初始化。梯度审计显示死参数 86 → 6 → 0（AdamW 两步内全开）。

## 三、损失

```
L = L_final^RGB + L_final^TIR
  + w_self · (L_self^RGB + L_self^TIR)
  + w_prop · (L_prop^RGB + L_prop^TIR)
  + λ_match · L_match
  + w_cons  · L_cons
```

| 项 | 内容 | 默认权重 |
|---|---|---|
| `L_final^m` | `L_QFL + λ_iou L_CIoU + λ_l1 L_L1`，类别感知（QFL 目标为一热类别 × 分配框 IoU） | `λ_iou=2.5`, `λ_l1=1.0` |
| `L_self^m` | 同样三项，输入为未融合的 `z_m` / `S_m` | `w_self=0.5` |
| `L_prop` | `L_heatmap + λ_pbox L_CIoU_coarse + λ_quality L_quality`（逐尺度、逐类别） | `w_prop=0.5`, `λ_pbox=1.5`, `λ_quality=0.5` |
| `L_match` | `CE(A_RT, target_RT) + CE(A_TR, target_TR)`，只对**确实存在对应**的 query 行计算（没有对应行不编造目标） | `λ_match=1.0` |
| `L_cons` | `JS(p_self ‖ p_other)`，配对来自①真实对应；②训练进度 ≥ `cons_start_fraction` 后的**双向互选且 Top1−Top2 间距 ≥ `cons_margin`** | `w_cons=0.1` |

* `L_match` / `L_cons` 都可关闭：`model.use_match_loss=false` / `model.use_cons_loss=false`（关闭后对应 loss 项与日志项都不再出现）。
* 没有实例对应标注时 `L_match=0`：`corr_pairs` 缺失即自动跳过。**禁止**用同数组下标、同类、最近坐标强行构造对应关系
  （`identity_matches` 明确实现为"候选 → 本侧 GT 槽 → 对侧 GT 槽"两跳查询，且两侧目标数量可以不同）。
* 默认关闭 NWD（V4 的 `L_final` 不含 NWD 项；`use_nwd=false`）。

## 四、配置（全部可调）

| 配置项 | 含义 | 默认 |
|---|---|---|
| `model.n_cand` | K（每模态候选数，也是相似度矩阵边长） | 128（v4 配置） |
| `model.cand_levels` / `cand_min_per_level` | 参与预测的尺度 / 每尺度最低配额 | P2-P5 / 8 |
| `model.num_classes` | 类别数（1 保持单 logit 约定） | 1 |
| `model.roi_size` / `roi_sampling_ratio` | S 的空间尺寸 / RoIAlign 采样率 | 3 / 2 |
| `model.retrieval_dim` | 检索维度（W_Q、W_K 为 128×64） | 64 |
| `model.td_top_l` / `td_samples` | Top-L / 每 anchor 采样点数（→ 局部特征数 = 二者乘积） | 2 / 4 |
| `model.alpha_init` | α 初值 | 0.1 |
| `model.lambda_iou` / `lambda_l1` | 最终检测损失权重 | 2.5 / 1.0 |
| `model.w_self` / `w_prop` | 辅助单模态 / proposal 权重 | 0.5 / 0.5 |
| `model.lambda_pbox` / `lambda_quality` | 粗框 CIoU / quality | 1.5 / 0.5 |
| `model.lambda_match` / `w_cons` | 匹配 / 一致性权重 | 1.0 / 0.1 |
| `model.cons_start_fraction` / `cons_margin` | 互选配对的开启进度 / 相似度间距阈值 | 0.5 / 1.0 |
| `model.use_match_loss` / `use_cons_loss` | 两个新损失的开关 | true / true |
| `model.use_td_fusion` | 关掉即退回纯独立检测（v4 版 A0） | true（stage 1 为 false） |

## 五、运行

```bash
PY=/home/yangjuanfeng/lab/envs/venv/bin/python
cd /home/yangjuanfeng/lab/projects/SkyGuard-RGBT/pgsf-det-v4

# 单元/回归测试（含 v1/v2/v3 兼容）
$PY -m unittest discover -s tests -v
# 全参数梯度审计（AdamW，6 步内应全部打开）
V4_DEEP=1 $PY tests/test_v4.py DeepGradientAudit -v
# 前向/反向/形状/显存/延迟体检
$PY scripts/check_forward.py --config configs/pgsf_v4_stage2.yaml --batch 1

# 两阶段训练（2×10GB RTX 3080，AMP，每卡 batch 2）
$PY scripts/train_v4.py --config configs/pgsf_v4_stage1.yaml --gpus 0,1
$PY scripts/train_v4.py --config configs/pgsf_v4_stage2.yaml --gpus 0,1 \
    --ckpt outputs/v4_stage1/ckpt/best.pt

# 评估 / 推理（推理不需要任何 GT 字段，也不做 GT 注入）
$PY scripts/train_v4.py --config configs/pgsf_v4_stage2.yaml --eval-only \
    --ckpt outputs/v4_stage2/ckpt/best.pt --split val
$PY scripts/infer_v4.py --ckpt outputs/v4_stage2/ckpt/best.pt --split val --n 32 \
    --out outputs/v4_val_dets.json
```

推理契约（`tests/test_v4.py::InferenceContract`）：
* 只传 `rgb/tir/rgb_hw/tir_hw` 即可，模型不读任何 GT 字段；
* `cand['injected']` 恒为 0（训练期的 GT 候选注入在 `model.training=False` 下不触发）；
* 改动冻结的 `_affine_A` 输出逐比特不变。

## 八、尚未完成（诚实说明）

* 未做全量训练与正式 val/test 评估，因此**没有**本版本与 v2/v3/官方基线的性能对比数字；
  当前交付是"可运行、可审计、被测试覆盖"的实现，不是"已证明更强"的结果。
* 多目标/多类别的训练效果只在合成数据与单元测试层面验证过（UAV-CB 每模态单目标）。
* `L_match` 是否真有增益取决于数据集是否提供可靠的跨模态实例对应；UAV-CB 的单目标帧是 1↔1 的唯一双射，
  因此 v4 配置里 `pair_by_index=true` 是精确结论而非顺序假设；换成多目标数据集时应改为显式实例 ID 文件。
